# Spotlight Cue Viewer

手動スポットライトの操作指示CSVを、現場で見やすく表示する依存ライブラリなしのWebアプリです。

## 使い方

### いちばん簡単

1. このフォルダでHTTPサーバーを起動します。
2. ブラウザで開きます。
3. `data.csv` が自動で読み込まれます。

例:

```bash
python3 -m http.server 8000
```

その後 `http://localhost:8000/` を開いてください。

### CSVをその場で差し替える

画面右上の「CSVを開く」またはドラッグ&ドロップで任意のCSVを読み込めます。

## 最新データへの更新

運用中のCSVを `data.csv` に置き換えるだけで、次回読み込み時に最新データを表示します。`fetch(..., { cache: 'no-store' })` にしてあるので、通常のHTTP配信では古いCSVを掴みにくい構成です。

## CSVの表記揺れ対応

- UTF-8 / Shift_JIS を自動判定
- `,` / TAB / `;` 区切りを自動判定
- 「タイミング / きっかけ / キュー / Cue / Timing / 歌詞」等をタイミング列として認識
- 「調光 / 照明 / Lighting / Light」等を調光列として認識
- 上記以外の列はスポット担当列として自動表示（A/B/Cなど列が増えても対応）
- 全角・半角や空白・一部記号差を吸収して判定
- `↓ / 〃 / 同 / 同上 / 継続 / keep / same` は直前指示の継続として解決し、「継続」バッジ付きで実内容を表示
- `消 / 消灯 / OFF / なし / × / -` は消灯系として視覚的に弱く表示
- `赤 / 青 / 水 / 黄 / 緑 / オレ(橙) / 生(白)` などの代表的な色語を強調

※ CSVとして列数が壊れている行（引用符なしでセル内にカンマを入れた場合など）は完全には推測できないため、警告を表示します。

## 操作

- 行クリック: 現在キューを選択
- 行ダブルクリック / Enter: そのキューからライブ表示
- `Space` / `↓` / `J`: 次へ
- `Shift + Space` / `↑` / `K`: 前へ
- `Home`: 先頭
- `End`: 最後
- `L`: 一覧 / ライブ表示切替

## 構成

- `index.html` — UI
- `styles.css` — ダークモード専用スタイル
- `app.js` — CSV解析・表記揺れ吸収・キュー操作
- `data.csv` — 初期表示用CSV（差し替え可能）

外部ライブラリ、ビルド、CDNは不要です。
